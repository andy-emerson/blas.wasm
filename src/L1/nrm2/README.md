# nrm2 — Euclidean norm

$$\|x\|_2 = \sqrt{\sum_i x_i^{2}}\qquad(\text{complex: } \sqrt{\textstyle\sum_i |x_i|^2})$$

Four routines: `dnrm2`, `snrm2` (real), `dznrm2`, `scnrm2` (complex
vector, real result, in reference BLAS's two-letter spelling).

```text
dnrm2(x) -> f64
```

## What the result is, exactly

The sum of squares is a lane fold (four accumulator registers, fixed
final order), so the contract is an error bound against a scaled
compensated reference, with the same bits on every target because the
fold's order is fixed. The over/underflow behavior is LAPACK's: inputs
whose norm is near the overflow or underflow threshold (around
$10^{\pm 300}$ in f64, $10^{\pm 30}$ in f32) are tested explicitly and
come out finite and correct. One recorded deviation from the
reference: a vector holding both an infinity and a NaN returns the
infinity where the reference returns NaN (decision D13 in
`STATUS.md`).

## How it is computed

A reduction stream with a two-pass rescue. The fast path is one
streaming sum-of-squares pass; if the sum is non-finite (overflow) or
small enough that squares may have lost bits to subnormals
(underflow), the vector is rescaled by its largest magnitude and
streamed again. The guard semantics are LAPACK's scaled
sum-of-squares; the shape (one branch between two streaming passes
instead of a per-element branchy update) is this crate's, and it is
what lets the fast path run at stream speed. `dznrm2` and `scnrm2` are
pure delegations: $\sum |x_i|^2 = \sum (\mathrm{re}_i^2 + \mathrm{im}_i^2)$
is the sum of squares of the $2n$-real view, so the real routine, its
stream and its rescue carry over unchanged. The square root is the
crate's vendored `sqrt` (`src/math.rs`), cross-checked bit for bit
against libm on every gate run.

## Performance

n = 2048, percentage of the fastest same-run memory stream, two runner
draws (the Level 1 README has the table and its provenance): f64
47–53%, f32 46%, c64 45%, c32 45–48%; against the read path, which is
the honest ceiling for a one-array reduction, 73–100%.

## Tests

`tests/L1/dnrm2.rs`, `snrm2.rs`, `dznrm2.rs`, `scnrm2.rs`: error bounds
against a scaled compensated reference at every length through the
tail; the overflow and underflow guard cases at each type's range.
