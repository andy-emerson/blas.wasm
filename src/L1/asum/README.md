# asum — sum of absolute values

$$\sum_i |x_i| \qquad(\text{complex: } \textstyle\sum_i |\mathrm{re}\,x_i| + |\mathrm{im}\,x_i|)$$

Four routines: `dasum`, `sasum` (real), `dzasum`, `scasum` (complex
vector, real result). Reference BLAS sums component magnitudes for the
complex form, not moduli; that is the interoperability contract and it
is kept.

```text
dasum(x) -> f64
```

## What the result is, exactly

A lane fold (four accumulator registers, absolute value in-lane, fixed
final order): bounded against a compensated reference, the same bits
on every target.

## How it is computed

A reduction stream. It is 3.5–4× faster than the plain loop on every
runner draw of the campaign that produced it, because the plain loop's
serial chain of dependent adds is latency-bound, not bandwidth-bound.
`dzasum` and `scasum` are pure delegations: the component sum is the
real routine over the $2n$-real view.

draws (the Level 1 README has the table and its provenance): f64

73–100%.
