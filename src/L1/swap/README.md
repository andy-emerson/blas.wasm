# swap — exchange two vectors

$$x \leftrightarrow y$$

Four routines: `dswap`, `sswap`, `zswap`, `cswap`.

```text
dswap(x, y)
```

## What the result is, exactly

Bytes move unchanged; no rounding contract. A length mismatch is an
error.

## How it is computed

An elementwise stream, two f64 or four f32 lanes per register,
unrolled twice. The SIMD loop beat the compiler's auto-vectorized
plain loop by 1.15–1.33× on three runner draws in the campaign that
produced it, which is why it is kept. `zswap` and `cswap` are pure
delegations to the real swap over the $2n$-real view.

## Performance

n = 2048, percentage of the fastest same-run memory stream, two runner
draws (the Level 1 README has the table and its provenance): f64
93–97%, f32 73–76%, c64 100%, c32 89–98%.
