# copy — copy a vector

$$y \leftarrow x$$

Four routines: `dcopy`, `scopy`, `zcopy`, `ccopy`.

```text
dcopy(x, y)
```

## What the result is, exactly

Bytes move unchanged; there is no rounding contract to state. A length
mismatch is an error.

## How it is computed

An elementwise stream, two f64 or four f32 lanes per register,
unrolled twice: a consistency decision on top of a measured no-harm,
since a copy runs at the memory ceiling either way and no speed claim
attaches to the loop over `memcpy`. `zcopy` and `ccopy` are pure
delegations to the real copy over the $2n$-real view.

## Performance

n = 2048, percentage of the fastest same-run memory stream, two runner
draws (the Level 1 README has the table and its provenance): f64
52–57%, f32 45–54%, c64 62–63%, c32 52–58%. A copy reads one array and
writes another, so against the fastest read-modify-write stream it
cannot reach 100%; the row is priced against that stream for
consistency with the rest of the table.
