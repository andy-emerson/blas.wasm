# rotg — generate a plane rotation

Given $(a, b)$, find $(c, s, r)$ with
$$c\,a + s\,b = r,\qquad c\,b - s\,a = 0,\qquad c^{2} + s^{2} = 1$$
(complex: $c$ real, $s$ and $r$ complex, $-\overline{s}\, a + c\, b = 0$,
$c^{2} + |s|^{2} = 1$). Four routines: `drotg`, `srotg`, `zrotg`,
`crotg`; each returns the rotation as a value (`Givens` with $c$, $s$,
$r$ for the real forms; `ZGivens`/`CGivens` for the complex ones).

```text
drotg(a, b) -> Givens
```

## What the result is, exactly

Reference BLAS's guarded scalar arithmetic, kept verbatim for its
proven numerics: the real forms' anti-overflow scaling, the complex
forms' moduli through the overflow-safe `hypot` (vendored in
`src/math.rs`, cross-checked bit for bit against libm on every gate
run), the norm formed from scaled moduli, and the phase factor
$a / |a|$ carrying $r$'s complex sign. The reference's $a = 0$ case
($c = 0$, $s = 1$, $r = b$) is reproduced. The classic `z`
reconstruction output of the real forms is omitted; no consumer wants
it. Tested by the defining identities, the reference edge cases, and
inputs at the extremes of each type's range.

## How it is computed

No arrays, so no lanes: a few guarded scalar operations, inlined so a
sweep that generates many rotations pays no call.
