# syr2k — symmetric and Hermitian rank-2k update

$$C \leftarrow \alpha\,\mathrm{op}(A)\,\mathrm{op}(B)^{T} + \alpha\,\mathrm{op}(B)\,\mathrm{op}(A)^{T} + \beta C,$$

one triangle of the $n \times n$ $C$ stored. Six routines: `dsyr2k`,
`ssyr2k` (real), `zher2k`, `cher2k` (Hermitian: $\alpha A B^{H} +
\overline{\alpha} B A^{H}$, $\beta$ real, the diagonal ends exactly
real), `zsyr2k`, `csyr2k` (complex symmetric). $\mathrm{op}(A)$ and
$\mathrm{op}(B)$ are $n \times k$.

```text
dsyr2k(uplo, trans, n, k, alpha, a, lda, b, ldb, beta, c, ldc, work)
```

`work` is `dsyr2k_work(trans, n, k)` elements: zero for the
no-transpose form, two $n \times k$ transposed copies for `Trans`.

## What the result is, exactly

For each stored element, $\beta c_{ij}$, then for each $l$ in
ascending order the $A$-sourced product and then the $B$-sourced one:
the plain two-stream sweep's order, reproduced bit for bit by the
tuned shape (tested by replay). The Hermitian forms' column scalars
are $\alpha\,\overline{b_{jl}}$ on $A$'s column and
$\overline{\alpha a_{jl}}$ on $B$'s; the diagonal's imaginary part is
set to exactly zero after each column, and with $\beta = 1$ and
nothing to add the routine returns before touching $C$.

## How it is computed

The truncated four-column fan-out sweep in every type (`CA+FO`): four
stored columns grouped so each inner column of $A$ and of $B$ streams
once per group over the common triangle segment, the ragged edge
scalar in the same order. This is the shape `syrk` used before the
K1 campaign; syr2k was not moved onto the packing layer and is the
one real Level 3 row still on the sweep.

## Performance

**Against the machine** (n = 512, same-run peak probe, two draws; the
probe's defect is in the Level 3 README): syr2k f64 38–49%, f32
47–56%; her2k c64 71–92%, c32 74–92%. The real rows are the sweep's
rate, about half the gemm kernel's; there is no B0 row for this
family yet.

**What is left.** Two rank-k updates through the `syrk` packed shape,
which exists: pack $A$ as the left panel and $B$ as the right with
$\alpha$ folded in, then the roles swapped, each tile's terms in the
sweep's $A$-then-$B$ order per $l$. Recorded in `STATUS.md` under
"Levers".

## Tests

`tests/L3/dsyr2k.rs`, `ssyr2k.rs`, `zher2k.rs`, `cher2k.rs`,
`zsyr2k.rs`, `csyr2k.rs`: the bit-for-bit replay of the two-stream
order, both triangles; the `Trans` form equal to the no-transpose call
on explicit transposes; the Hermitian diagonal exactly real;
`semantics.rs` for the $\alpha = 0$, $k = 0$ and $\beta = 1$ rules;
`errors.rs` for the argument checks.
