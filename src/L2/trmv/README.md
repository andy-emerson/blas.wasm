# trmv — triangular matrix–vector multiplication, in place

$$x \leftarrow \mathrm{op}(A)\, x,$$

$A$ an $n \times n$ triangular matrix (upper or lower, unit or
non-unit diagonal), $x$ overwritten. Four routines: `dtrmv`, `strmv`,
`ztrmv`, `ctrmv`.

```text
dtrmv(uplo, trans, diag, n, a, lda, x)
```

## What the result is, exactly

**No transpose.** Reference `dtrmv`'s column order: for an upper $A$
the columns ascend, for a lower $A$ they descend, each column adding
$x_j\, a_{ij}$ into the elements above (or below) the diagonal and
then writing the diagonal element; each $x_j$ is consumed before its
own slot is overwritten. The four-column shape performs exactly those
roundings in that order and is bit for bit the plain column loop
(tested by replay).

**Transposed.** Element $j$ is the dot product of the stored segment of
column $j$ with $x$, and that is the Level 1 `dot` kernel's fold
(four accumulators, fixed final order), which the tests replay bit for
bit; it is a different rounding sequence from the reference's
sequential sum, equally valid, and identical on every target. The
alternative, a copy of $\mathrm{op}(A)$, costs as much as the operation
and was not raced.

The reference's zero-multiplier skip is not mirrored (decision D12).

## How it is computed

**No transpose: four-column fan-in in the reference's order.** Groups
of four columns share one pass over $x$'s common segment
(`daxpy4in` in `src/kernels.rs`, sources in the reference's column
order), so $x$'s read-modify-write traffic drops four times; the
ragged band of up to three rows and the diagonal writes run scalar in
the original step order. The four group values are provably untouched
until their step, which is what keeps the order the reference's.

**Transposed: a dot-fold reduction per stored column** (`dtrmv_t_k`
and twins), the shape `gemv_t` already uses.

## Performance

n = 2048, percentage of the fastest same-run memory stream, two runner
draws (the Level 2 README has the whole table and its provenance):
f64 60–66%, f32 54–59%, c64 47–52%, c32 60–65% (the no-transpose form;
the transposed form is the `gemv_t` shape's rate).

## Tests

`tests/L2/dtrmv.rs`, `strmv.rs`, `ztrmv.rs`, `ctrmv.rs`: the
bit-for-bit replay of the reference column order, both triangles,
unit and non-unit; the transposed form replayed against the dot
kernel's fold and bounded against the no-transpose call on an explicit
transpose; `errors.rs` for the argument checks.
