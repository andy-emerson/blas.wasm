# syr — symmetric and Hermitian rank-1 update

$$A \leftarrow A + \alpha\, x\, x^{T},$$

one triangle of the $n \times n$ $A$ stored and updated. Four routines:
`dsyr`, `ssyr` (symmetric), `zher`, `cher` (Hermitian: $x x^{H}$ with
$\alpha$ real, and the stored diagonal ends exactly real).

```text
dsyr(uplo, n, alpha, x, a, lda)
```

## What the result is, exactly

Stored column $j$ gains $(\alpha x_j)\, x_i$ over its stored segment:
one multiply for the scalar, then one multiply and one add per
element, in that order, the plain column-axpy definition reproduced
bit for bit (tested by replay). The Hermitian forms use the scalar
$\alpha\,\overline{x_j}$ on the strict segment, and the diagonal
update $\mathrm{re}(x_j \cdot t)$ is stored with imaginary part exactly
zero, reference `zher`'s `DBLE()` convention: the layer's Hermitian
invariant that stored diagonals stay exactly real. The reference's
zero-multiplier skip is not mirrored (decision D12).

## How it is computed

One Level 1 `axpy` stream per stored column segment, the scalar
formed once per column. A rank-1 update is a pure stream and already
at the memory ceiling.

## Performance

n = 2048, percentage of the fastest same-run memory stream, two runner
draws (the Level 2 README has the whole table and its provenance):
syr f64 100%, f32 87–90%; her c64 60–64%, c32 85–93%.

## Tests

`tests/L2/dsyr.rs`, `ssyr.rs`, `zher.rs`, `cher.rs`: the bit-for-bit
replay of the column order, both triangles, the Hermitian diagonal
ending exactly real (+0.0 imaginary); `errors.rs` for the argument
checks.
