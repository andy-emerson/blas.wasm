# syr2 — symmetric and Hermitian rank-2 update

$$A \leftarrow A + \alpha\, x\, y^{T} + \alpha\, y\, x^{T},$$

one triangle of the $n \times n$ $A$ stored and updated. Four routines:
`dsyr2`, `ssyr2` (symmetric), `zher2`, `cher2` (Hermitian:
$\alpha x y^{H} + \overline{\alpha}\, y x^{H}$, the stored diagonal
ending exactly real).

```text
dsyr2(uplo, n, alpha, x, y, a, lda)
```

## What the result is, exactly

Stored column $j$ gains two column-axpy passes in order: first
$(\alpha y_j)\, x_i$, then $(\alpha x_j)\, y_i$, each one multiply and
one add per element. The Hermitian forms' scalars are
$\alpha\,\overline{y_j}$ and $\overline{\alpha x_j}$ (the conjugations
on the scalars, never on a stream), and the diagonal update is real
and stored with imaginary part exactly zero. Bit for bit the plain
definition in that order (tested by replay). The reference's
zero-multiplier skip is not mirrored (decision D12).

## How it is computed

Two Level 1 `axpy` streams per stored column segment; the second rides
the cache lines the first has just warmed. A pure stream, so no
four-column shape applies.

## Performance

n = 2048, percentage of the fastest same-run memory stream, two runner
draws (the Level 2 README has the whole table and its provenance):
syr2 f64 50–51%, f32 45–46%; her2 c64 32–35%, c32 47–49%. The two
passes per column halve the rate against `syr`; a fused two-scalar
pass (one read of the column, both products) is the obvious lever and
has not been raced.
