# trsv — triangular solve with one right-hand side, in place

$$x \leftarrow \mathrm{op}(A)^{-1}\, x,$$

$A$ an $n \times n$ triangular matrix (upper or lower, unit or
non-unit diagonal), $x$ overwritten with the solution. Four routines:
`dtrsv`, `strsv`, `ztrsv`, `ctrsv`. No singularity check: a zero
diagonal yields infinities or NaNs, as in the reference.

```text
dtrsv(uplo, trans, diag, n, a, lda, x)
```

## What the result is, exactly

**No transpose.** Reference `dtrsv`'s elimination order: for an upper
$A$ the unknowns are solved from the last to the first, each divided
by its diagonal ($x_j \leftarrow x_j / a_{jj}$, a division, not a
reciprocal multiply) and then eliminated from the elements above; for
a lower $A$ the mirror. The four-column shape performs those roundings
in that order and is bit for bit the plain loop (tested by replay and
by residual). The complex divisions use Smith's algorithm, the guarded
`/` of `C64`/`C32` (LAPACK's `dladiv` shape).

**Transposed.** Each new unknown is the dot product of the stored
segment of its column with the already-solved part of $x$, the Level 1
`dot` kernel's fold, replayed bit for bit by the tests; then the
division.

The reference's zero-multiplier skip is not mirrored (decision D12).

## How it is computed

**No transpose: divide, then four-column fan-in.** The four divisions
and the in-group elimination band of up to three rows run scalar in
the reference's order (the values are sequentially dependent), then
the four solved unknowns eliminate from the common remaining segment
in one shared pass (`daxpy4in`, sources in the same step order),
cutting $x$'s read-modify-write traffic four times.

**Transposed: a dot-fold reduction per stored column** (`dtrsv_t_k`
and twins) followed by the division.

## Performance

n = 2048, percentage of the fastest same-run memory stream, two runner
draws (the Level 2 README has the whole table and its provenance):
f64 59–65%, f32 53–57%, c64 47–53%, c32 54–56%.

## Tests

`tests/L2/dtrsv.rs`, `strsv.rs`, `ztrsv.rs`, `ctrsv.rs`: the
bit-for-bit replay of the reference elimination order, both
triangles, unit and non-unit, plus the residual $\|A x - b\|$ bound;
the transposed form replayed against the dot kernel's fold and
bounded against the no-transpose call on an explicit transpose;
`errors.rs` for the argument checks.
